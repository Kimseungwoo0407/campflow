# 확정 여행 브리프

## 일정

- 시작: 2026년 8월 29일(토)
- 종료: 2026년 8월 30일(일)
- 기간: 1박 2일
- 기준 시간대: Asia/Seoul
- 상태: 사용자 확정

## 제품 반영 규칙

- 날짜를 다시 묻는 설문이나 투표는 만들지 않는다.
- 여행 생성 시 위 시작일과 종료일을 기본값이 아닌 **확정값**으로 사용한다.
- 일정, 숙소, 준비물, 투표 마감일 등 후속 기능은 이 날짜를 기준으로 계산한다.
- 사용자가 명시적으로 일정을 변경하기 전까지 날짜 편집 UI는 잠금 상태로 표시한다.
- Phase 2 여행 도메인과 초기 데이터에 `2026-08-29`~`2026-08-30`을 반영한다.

## 캐릭터 제작 메모

- 대상: 승우, 기훈, 성진, 경윤
- `character_기준.txt`의 대화 내용은 각 인물의 역할과 성향을 설명하는 근거로만 사용한다.
- 최종 이미지는 귀여운 마스코트가 아닌 초사실주의 인물 이미지로 제작한다.
- 실제 외모를 임의로 추측하지 않는다. 얼굴·체형·헤어스타일을 보존하려면 각 인물이 식별되는 원본 사진이 필요하다.
